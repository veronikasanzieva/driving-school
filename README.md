# Автошкола "Драйв"

Краткое описание проекта: Сайт для автошколы с информацией об услугах, галереей автопарка, мини-тестом по ПДД и формой записи.

## Функционал
- Адаптивный дизайн (Flexbox/Grid).
- Переключение темной/светлой темы (с сохранением в localStorage).
- Режим для слабовидящих (высокий контраст, изменение размера шрифта, озвучивание текста).
- Мини-тест по ПДД с подсчетом результатов.
- Слайдер изображений без сторонних библиотек.
- Фильтрация услуг через живой поиск.
- Модальное окно с деталями.
- Переключение языка (RU/EN).
- Плавная прокрутка по якорям и кнопка "Наверх".

## Как запустить проект локально
1. Скачайте проект (нажмите зеленую кнопку **Code** -> **Download ZIP**).
2. Распакуйте архив в любую папку.
3. Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Edge).
